## 1. 筛选标准

- 画面只有一个主要人物，且全身（头顶到脚底）可见；允许极小的背景人物，但不收多人合影/群像。
- 人物占画面高度至少约 1/4；最终图片高度 957–2000 px（均不低于 800 px）。
- 动作类型优先：武术、醉拳、格斗、舞蹈、体育、动作电影感照片；姿态覆盖站立侧踢、腾空飞踢、弓步/低架、单腿平衡、芭蕾、街舞 freeze、体操空翻、跳远、排球扣杀等。
- 排除：半身/裁切、坐姿/躺姿、卡通/动漫、严重透视、超大字幕/水印、明显拼接/合成、纯背景无人。
- 全部为真人照片；不含动漫角色。

## 4. 质检与人体检测

- 用 PIL 逐张打开并 `verify()`：15 张全部可读，无损坏；实际宽高记录于 `manifest.json` 的 `width` / `height`。
- 使用 **torchvision FasterRCNN MobileNetV3-Large FPN**（COCO person 类别，score ≥ 0.5）做辅助检测；`manifest.json` 中记录了每张图的 `person_count_score_ge_0.5`、`main_bbox_px`、`main_bbox_norm`、`main_height_ratio`。
- 所有图片均经人工逐张目检：单一主要人物、全身完整；13 与 14 号背景有少量观众（检测器各报告 11 个背景人物框），但主要人物 bbox 高度占比分别为 59% / 88%，不构成群像。
- 01 号是 724×957 的老照片扫描件（高度 957 px），有轻微颗粒；04 号脚趾接近画面左边缘但完整可见；08/09 号人物占画面高度约 35% / 38%，满足最低 1/4 要求。

## 5. 失败来源与风险说明

- **网络**：本机直连 Wikimedia 失败，按先前约定走系统代理 `127.0.0.1:7897`。`upload.wikimedia.org` 原图下载多次返回 429（限流），最终多数使用 `thumb.wikimedia.org` 的 1920px/1280px 缩略图，未对 01 号做放大；因此部分文件不是原始像素尺寸。
- **未采用的候选**：多人对打/群像（如跆拳道对打、capoeira 群体、芭蕾三人 leap、拳击对练）、半身/裁切、低分辨率（<800px 高）、插画/合成图等已剔除；`Tadyakamao.jpg` 等少数候选因 429/下载失败未纳入。
- **版权/肖像风险**：所有图片为公共领域或 CC 许可，但许可不包含肖像权/模特授权；若用于商业宣传、训练数据集再分发或公开展示，请逐张核对来源页的署名要求与当地法律。CC BY-SA 存在 copyleft 义务。
- **技术风险**：剪影图（02/03/05）缺乏纹理与面部信息，2D 姿态检测可能不稳定；08/09 人物相对画面较小；13/14 背景观众可能干扰检测器；建议在评估时结合人工关键点检查。
- **来源结构**：本轮未使用 Internet Archive 电影截帧（下载/转码成本高），也未直接调用 Pexels/Unsplash API（需密钥）；如需要更多「电影截帧」类别，可下一轮补齐。
